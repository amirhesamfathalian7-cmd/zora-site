# پرنده‌ی پیام‌رسان اپدیت — راهنمای یکپارچه‌سازی با اپ zora 🐦

این پکیج، سیستمی است که هر وقت نسخه‌ی جدیدی از zora منتشر شود، **داخل خود اپ** یک
پرنده‌ی پیام‌رسان زیبا می‌فرستد تا به کاربرانی که نسخه‌ی قدیمی دارند بگوید:

> «اپدیت جدید از راه رسید دوست من! 🎉 همین حالا می‌تونی از سایت رسمی ما دانلودش کنی و لذت ببری ❤️🌊»

و با یک کلیک، کاربر به صفحه‌ی دانلود سایت رسمی می‌رسد.

---

## چطور کار می‌کند؟

```
سایت رسمی  ────/api/version────▶  { version: "1.1.0", ... }
   ▲                                      │
   │                            اپ zora هر ۶ ساعت یک‌بار چک می‌کند
   │                                      │
   └── کلیک کاربر ◀── پرنده: «اپدیت جدید…»  ◀──  if (سایت > اپ) → پرنده پرواز می‌کند
```

- کاملاً **بی‌صدا و امن**: در حالت آفلاین یا هر خطا، هیچ چیزی نشان داده نمی‌شود.
- هر ۶ ساعت یک‌بار fetch واقعی دارد و نتیجه در localStorage کش می‌شود.
- اگر کاربر «بعداً» بزند، فقط برای همان نسخه دیگر مزاحمش نمی‌شوید.

---

## نصب (۳ قدم)

### قدم ۱ — کپی فایل‌ها

هر ۳ فایل را در پروژه‌ی Next.js اپ کپی کنید:

| فایل در این پکیج | مقصد در پروژه‌ی اپ |
|---|---|
| `zora-config.ts` | `src/lib/zora-config.ts` |
| `update-check.ts` | `src/lib/update-check.ts` |
| `UpdateBird.tsx` | `src/components/update-bird.tsx` |

> نکته: اگر پروژه‌ی اپ، alias `@/` دارد (پیش‌فرض Next.js + shadcn است) هیچ تغییری لازم نیست.

### قدم ۲ — رندر کردن پرنده در صفحه‌ی اصلی

در `src/app/page.tsx` (لندینگ اپ):

```tsx
import { UpdateBird } from "@/components/update-bird";

export default function Home() {
  return (
    <>
      {/* ...بقیه‌ی صفحه... */}
      <UpdateBird />
    </>
  );
}
```

### قدم ۳ — تنظیم آدرس سایت

در `zora-config.ts` مقدار `OFFICIAL_SITE_URL` را با آدرس واقعی سایت رسمی
(همین سایتی که ساخته شده) عوض کنید. همین!

---

## چرخه‌ی انتشار اپدیت (از این به بعد)

1. در اپ: `APP_VERSION` را بالا ببرید (مثلاً `"1.0.0"` → `"1.1.0"`) و exe جدید بسازید.
2. در سایت: در فایل `src/lib/zora.ts` مقدار `RELEASE.version` و `notes` را همان نسخه کنید.
3. فایل‌های exe جدید را در پوشه‌ی `download/` کنار سایت قرار دهید (یا روی هاست آپلود کنید).
4. تمام! کاربران نسخه‌های قبلی، پرنده را می‌بینند و از سایت دانلود می‌کنند. 🎉

## نکته‌ی Electron (اختیاری ولی پیشنهادشده)

برای اینکه دکمه‌ی «دانلود از سایت رسمی ما» مرورگر واقعی ویندوز را باز کند
(نه پنجره‌ی داخل اپ را)، در `desktop/main.js` این هندلر را به BrowserWindow اضافه کنید:

```js
win.webContents.setWindowOpenHandler(({ url }) => {
  if (/^https?:\/\//i.test(url)) {
    require("electron").shell.openExternal(url);
    return { action: "deny" };
  }
  return { action: "allow" };
});
```

## تست سریع

برای دیدن پرنده بدون اینکه واقعاً اپدیت داده باشید، موقتاً در `zora-config.ts` بنویسید:

```ts
export const APP_VERSION = "0.0.1"; // پرنده حتماً می‌آید
```

و `force` را صدا بزنید: `checkForUpdate(true)` — بعد از تست به `"1.0.0"` برگردانید.
